# Galactic Cinema Days - Event Schedule

An HTML and CSS project focusing on styling tables and working with advanced CSS background properties. 

## 📝 About The Project

This is a visually appealing, 3-day event schedule for a fictional "Space Movies Marathon". The primary goal of this project was to practice fundamental CSS styling techniques, specifically mastering background imagery and table customization, without relying on advanced layout modules like Flexbox or Grid. 

## 🚀 Key Concepts & Technologies Practiced

* **HTML5 Tables:** Proper semantic structuring using `<thead>`, `<tbody>`, `<tr>`, `<th>`, and `<td>`.
* **CSS Backgrounds:** Implementing a full-screen, fixed background image using `background-image`, `background-size: cover`, and `background-position`.
* **CSS Pseudo-classes:** Utilizing `:nth-child()`, `:first-child`, and `:last-child` for dynamic row styling and alternating background colors to enhance readability.
* **Global Resets:** Applying `box-sizing: border-box` and resetting default browser margins/paddings.
* **Table Styling:** Managing cell spacing with `border-collapse` and applying paddings for a clean UI.

## 📂 Project Structure

* `index.html` - The main HTML skeleton and table layout.
* `style.css` - The stylesheet containing background rules, table styling, and color schemes.
* `img/` - Directory containing the background asset.

## 💻 How to Run

Simply clone the repository and open `index.html` in any modern web browser. No local server or build tools are required.
